# 이번 학기 마지막 수업 토론 문서

이번 학기 마지막 수업에서 진행할 토론용 문서입니다.

## 1. 각 주제별 사회자 질문

### 1) AI 시대에는 개발 실력보다 문제 정의 능력이 더 중요하다
- AI가 코드를 잘 써주는 시대에도, 사람이 꼭 해야 하는 일은 무엇일까요?
- 문제를 잘 정의하는 능력은 왜 개발 실력보다 더 중요할 수 있을까요?
- 잘못된 문제를 빠르게 푸는 것과, 올바른 문제를 정확히 푸는 것 중 무엇이 더 가치 있을까요?

### 2) 학생 시절에는 특정 언어를 깊게 배우는 것보다 도구 활용 능력에 투자해야 한다
- 학생 시절에 한 가지 언어를 깊게 파는 것과 다양한 도구를 넓게 익히는 것 중 무엇이 더 중요할까요?
- 개발 도구를 잘 쓰는 능력이 앞으로의 실무에 얼마나 영향을 줄까요?
- 기초를 다지는 학습과 도구를 익히는 학습은 어떻게 균형을 맞춰야 할까요?

### 3) 앞으로 개발자의 경쟁력은 구현 속도보다 검증 능력에서 갈린다
- AI가 코드를 빠르게 만들수록, 왜 검증 능력이 더 중요해질까요?
- 빠르게 만든 코드와 정확하게 검증한 코드 중 어떤 것이 더 신뢰할 수 있을까요?
- 개발자가 결과를 검증하는 능력을 기르기 위해 무엇을 연습해야 할까요?

### 4) 좋은 개발자는 혼자 잘하는 사람보다 협업이 쉬운 사람이다
- 팀 프로젝트에서 기술 실력과 협업 능력 중 무엇이 더 큰 차이를 만들까요?
- 협업이 쉬운 사람은 어떤 특징을 가지고 있을까요?
- 혼자 잘하는 개발자와 함께 일하기 좋은 개발자 중 어느 쪽이 더 오래 경쟁력을 가질까요?

### 5) 바이브 코딩 시대에는 기술 실력보다 질문하는 능력이 더 중요하다
- 좋은 질문이 왜 좋은 결과로 이어질까요?
- AI 시대에 질문하는 능력이 개발자의 핵심 역량이 될 수 있을까요?
- 질문을 잘하는 사람과 답을 잘 만드는 사람 중, 누구의 역량이 더 먼저 필요할까요?

## 2. 찬반 토론용 한 줄 결론

### 1) AI 시대에는 개발 실력보다 문제 정의 능력이 더 중요하다
- AI가 코드를 대신 써주는 시대일수록, 무엇을 풀지 정하는 능력이 더 중요하다.

### 2) 학생 시절에는 특정 언어를 깊게 배우는 것보다 도구 활용 능력에 투자해야 한다
- 학생 때는 한 언어의 깊이보다, 빠르게 배우고 활용하는 도구 감각에 투자하는 것이 더 실용적이다.

### 3) 앞으로 개발자의 경쟁력은 구현 속도보다 검증 능력에서 갈린다
- 코드를 빨리 만드는 것보다, 그 코드가 맞는지 확인하는 능력이 더 큰 경쟁력이 된다.

### 4) 좋은 개발자는 혼자 잘하는 사람보다 협업이 쉬운 사람이다
- 실제 프로젝트에서는 혼자 뛰어난 사람보다 함께 일하기 쉬운 사람이 더 좋은 개발자다.

### 5) 바이브 코딩 시대에는 기술 실력보다 질문하는 능력이 더 중요하다
- AI를 잘 활용하려면 정답을 아는 것보다, 좋은 질문을 던지는 능력이 먼저 필요하다.
