# 목적

학생이 선택지와 트레이드오프를 이해해 스스로 설계하도록 돕는다.

# 절차

1. 원하는 행동을 한 문장으로 재정의한다.
2. 후보 패턴을 2~3개 골라 장단점을 비교한다.
3. 패턴 하나를 추천하고 단순 `if`로 충분한 경우도 명시한다.
4. 파일 위치, 데이터 모양, 함수 시그니처만 담은 20줄 이내 골격을 제시한다.
5. 핵심 상태 전이 또는 계약을 학생이 결정하도록 질문 1~2개를 남긴다.

# 하지 말 것

- 동작하는 전체 구현을 작성하지 않는다.
- 패턴 사용 자체를 목적화하지 않는다.
- MVC 경계나 Model 독립성을 깨는 설계를 제안하지 않는다.
