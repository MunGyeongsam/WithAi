# 챕터별 실습 코드

각 챕터의 실습 예제를 독립 실행할 수 있도록 정리한 폴더입니다.

## 실행 방법

```bash
# 각 챕터 예제는 해당 챕터의 .md 파일 하단 "실습" 섹션에 포함되어 있습니다.
# LÖVE2D 예제를 실행하려면:

mkdir ch02_bounce && cd ch02_bounce
# 해당 챕터의 실습 코드를 main.lua로 저장
love .
```

## 순수 Lua 예제 (LÖVE2D 불필요)

챕터 18의 직렬화 모듈 등은 순수 Lua로도 테스트 가능합니다:

```bash
lua serialize_test.lua
```
