# /start-session

1. 사용자에게 지난 세션의 **인계 메모**를 붙여 달라고 요청한다. 없으면 `worklogs/` 의 가장 최근 파일에서 "인계 메모"를 읽는다.
2. 이번 세션의 목표를 **한 문장**으로 사용자와 확정한다. 목표가 2개 이상이면 하나만 고르게 한다.
3. 수정 허용 파일 목록과 읽기 전용 파일 목록을 사용자와 확정한다.
4. `git status` 결과를 보여 주고, 커밋되지 않은 변경이 있으면 먼저 커밋할지 묻는다. (되돌리기 지점 확보)
5. `planner` 에이전트로 계획을 세운다. 코드는 수정하지 않는다.
6. 계획을 보여 주고 **사용자 승인을 기다린다.**
7. 확정한 목표, 파일 목록, 계획을 작업 로그용으로 5줄 이내로 요약해 준다.
