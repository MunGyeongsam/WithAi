# /end-session

1. `test-runner` 에이전트로 테스트와 `layer_check` 를 실행하고 결과를 보여 준다.
2. `git diff --stat` 과 `git diff` 로 바뀐 파일을 요약한다. 세션 시작 때 정한 **수정 허용 파일 밖의 변경**이 있으면 따로 표시한다.
3. `lua-reviewer` 에이전트로 변경을 리뷰한다.
4. 테스트 실패나 "수정 필요"가 있으면 여기서 멈추고 사용자에게 알린다. 자동으로 고치지 않는다.
5. `worklog-writer` 스킬로 이번 세션의 작업 로그 초안과 인계 메모를 작성한다. 프롬프트 원문은 그대로 옮긴다.
6. 커밋 메시지를 제안한다. (형식: `feat|fix|test|docs: 한 줄 요약`) 커밋은 사용자가 직접 한다.
7. "새 세션에서 인계 메모를 붙여 다음 태스크를 시작하라"고 안내한다.
