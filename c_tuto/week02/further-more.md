## 1. 고정 크기 정수 타입 (Fixed-width integers)

`int`의 크기가 플랫폼마다 다를 수 있으므로, 정확한 크기가 필요할 때:

```c
#include <stdint.h>
#include <stdio.h>

int main(void) {
    int8_t   tiny  = 127;        /* 정확히 8비트 (1바이트) */
    int16_t  small = 32767;      /* 정확히 16비트 */
    int32_t  med   = 2147483647; /* 정확히 32비트 */
    uint32_t pos   = 4000000000U;/* 부호 없는 32비트 */

    printf("tiny=%d, small=%d, med=%d, pos=%u\n",
           tiny, small, med, pos);
    return 0;
}
```

이 타입들은 네트워크 프로토콜, 파일 형식 등 비트 단위 정밀도가 필요한 곳에서 사용한다.

## 2. 부동소수점의 정밀도 한계

```c
#include <stdio.h>

int main(void) {
    float  f = 0.1f;
    double d = 0.1;

    printf("float  0.1 = %.20f\n", f);
    printf("double 0.1 = %.20lf\n", d);
    
    /* 비교 위험 */
    if (f == 0.1f) {
        printf("같다\n");
    }
    /* 이보다는 오차 범위로 비교 */
    if (f - 0.1f < 0.0001f && f - 0.1f > -0.0001f) {
        printf("거의 같다\n");
    }
    return 0;
}
```

출력:
```
float  0.1 = 0.10000000149011611938
double 0.1 = 0.10000000000000000555
```

> 0.1은 2진수로 정확히 표현할 수 없다. 항상 약간의 오차가 존재한다.

## 3. 비트 연산자 맛보기

| 연산자 | 의미 | 예시 |
|--------|------|------|
| `&` | 비트 AND | `0b1100 & 0b1010 = 0b1000` |
| `|` | 비트 OR | `0b1100 | 0b1010 = 0b1110` |
| `^` | 비트 XOR | `0b1100 ^ 0b1010 = 0b0110` |
| `~` | 비트 NOT | `~0b1100 = ...0011` |
| `<<` | 왼쪽 시프트 | `1 << 3 = 8` |
| `>>` | 오른쪽 시프트 | `8 >> 2 = 2` |

이 연산자들은 나중에(10~11주차) 비트 필드와 함께 다시 자세히 배운다.
