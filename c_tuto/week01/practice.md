## 문제 1: 자기소개 프로그램 (난이도: ★☆☆)

자신의 이름, 나이, 좋아하는 것 3가지를 출력하는 프로그램을 작성하시오.

출력 예시:
```
이름: 김철수
나이: 22
좋아하는 것: 독서, 음악, 산책
```

## 문제 2: 서식 출력 연습 (난이도: ★☆☆)

다음 출력을 정확히 재현하는 프로그램을 작성하시오.
(숫자는 계산식으로 작성할 것)

```
10 + 20 = 30
10 - 20 = -10
10 * 20 = 200
```

## 문제 3: 종료 코드 실험 (난이도: ★★☆)

1. `return 0;`인 프로그램을 빌드하고 실행한 뒤 `echo $?`로 종료 코드를 확인하시오.
2. `return 1;`로 바꿔서 같은 과정을 반복하시오.
3. 두 결과의 차이를 한 줄로 설명하시오.

## 문제 4: 경고 만들고 고치기 (난이도: ★★☆)

다음 코드를 `-Wall -Wextra` 옵션으로 빌드하면 경고가 나온다.

```c
#include <stdio.h>

int main(void) {
    int x;
    printf("%d\n", x);
    return 0;
}
```

1. 경고 메시지를 기록하시오.
2. 경고가 사라지도록 코드를 수정하시오.
3. 왜 이것이 위험한지 한 줄로 설명하시오.
