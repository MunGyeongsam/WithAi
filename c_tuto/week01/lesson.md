# Week 01 - C 언어와의 첫 만남: 프로그램은 어떻게 실행되는가

## 왜 C를 배우는가

컴퓨터는 0과 1만 이해한다. 하지만 사람은 0과 1로 대화하기 어렵다.
그래서 **프로그래밍 언어**라는 중간 언어가 필요하다.

C는 1972년에 만들어진 언어로, 지금까지 운영체제(Windows, Linux, macOS),
게임 엔진, 임베디드 시스템의 핵심에 쓰이고 있다.

C를 배우면 얻는 것:
- 컴퓨터가 실제로 어떻게 동작하는지 이해하게 된다.
- 다른 언어(Python, Java 등)의 기반을 이해하게 된다.
- "왜 이렇게 동작하는가"를 설명할 수 있게 된다.

## 핵심 개념 1: 소스 코드와 실행 파일

### 비유로 이해하기

요리에 비유하면:
- **소스 코드**(.c 파일) = 레시피(사람이 읽는 문서)
- **컴파일러**(compiler) = 요리사(레시피를 실제 요리로 바꾸는 존재)
- **실행 파일**(executable) = 완성된 요리(컴퓨터가 직접 실행하는 것)

C 언어에서는 소스 코드를 **직접 실행할 수 없다**.
반드시 컴파일러가 기계어(machine code)로 변환한 뒤에야 실행 가능하다.

### 빌드의 4단계

소스 코드가 실행 파일이 되기까지 4단계를 거친다:

```
[소스 코드] → 전처리 → 컴파일 → 어셈블 → 링크 → [실행 파일]
```

| 단계 | 하는 일 | 비유 |
|------|---------|------|
| 전처리(preprocessing) | #include 등 지시문 처리 | 레시피의 "참고" 부분을 본문에 합치기 |
| 컴파일(compilation) | C 코드를 어셈블리로 변환 | 한국어 레시피를 영어로 번역 |
| 어셈블(assembly) | 어셈블리를 기계어로 변환 | 영어를 컴퓨터 전용 암호로 변환 |
| 링크(linking) | 여러 조각을 하나로 합침 | 각 챕터를 한 권의 책으로 제본 |

## 핵심 개념 2: 최소 C 프로그램

### 가장 작은 프로그램

```c
#include <stdio.h>

int main(void) {
    printf("Hello, World!\n");
    return 0;
}
```

이 프로그램을 한 줄씩 해석하면:

| 줄 | 코드 | 의미 |
|----|------|------|
| 1 | `#include <stdio.h>` | "화면 출력 기능을 사용하겠다"는 선언 |
| 3 | `int main(void)` | 프로그램의 시작점(entry point) 선언 |
| 4 | `printf("Hello, World!\n");` | 화면에 글자를 출력하는 명령 |
| 5 | `return 0;` | "정상 종료"를 운영체제에 알림 |

### 핵심 규칙

- 모든 C 프로그램은 반드시 `main` 함수에서 시작한다.
- 문장(statement) 끝에는 반드시 세미콜론(`;`)을 붙인다.
- `\n`은 줄바꿈(새 줄로 이동)을 의미한다.
- `return 0`은 "문제 없이 끝났다"는 신호다.

## 핵심 개념 3: 빌드하고 실행하기

### 터미널에서 빌드하는 방법

```bash
gcc -std=c11 -Wall -Wextra hello.c -o hello
```

이 명령의 의미:
- `gcc` : C 컴파일러 프로그램
- `-std=c11` : C11 표준을 따르겠다
- `-Wall -Wextra` : 경고를 최대한 보여달라 (학습에 매우 유용)
- `hello.c` : 내가 만든 소스 파일
- `-o hello` : 결과물 이름을 hello로 하겠다

### 실행하는 방법

```bash
./hello
```

출력 결과:
```
Hello, World!
```

### 종료 코드 확인

```bash
echo $?
```

출력 결과: `0` (정상 종료를 의미)

## 핵심 개념 4: 경고(warning)는 학습 도구다

경고는 에러가 아니다. 프로그램은 실행된다.
하지만 경고는 **"지금은 괜찮지만 나중에 문제될 수 있다"**는 신호다.

예를 들어 이런 코드를 작성하면:

```c
#include <stdio.h>

int main(void) {
    int x;          // 값을 넣지 않고
    printf("%d\n", x);  // 바로 사용
    return 0;
}
```

컴파일러가 이런 경고를 준다:
```
warning: variable 'x' is uninitialized
```

의미: "x에 값을 넣지 않았는데 쓰려고 합니다. 의도한 건가요?"

**원칙: 경고 0개 상태를 항상 유지한다.**

---

## 오개념 경고 (자주 틀리는 포인트)

1. **"C 파일을 더블클릭하면 실행된다"** → 아니다. 반드시 컴파일 후 실행해야 한다.
2. **"세미콜론은 줄 끝에 붙이는 것"** → 줄이 아니라 **문장(statement)** 끝에 붙이는 것이다. 한 줄에 여러 문장이 올 수도 있다.
3. **"return 0을 안 써도 된다"** → C11에서는 생략 가능하지만, 명시적으로 쓰는 습관이 안전하다.

## 실습 시연

### 실습 1: 자기소개 프로그램

```c
#include <stdio.h>

int main(void) {
    printf("이름: 홍길동\n");
    printf("전공: 철학\n");
    printf("목표: C 언어 마스터\n");
    return 0;
}
```

빌드 및 실행:
```bash
gcc -std=c11 -Wall -Wextra intro.c -o intro
./intro
```

예상 출력:
```
이름: 홍길동
전공: 철학
목표: C 언어 마스터
```

### 실습 2: 숫자 출력

```c
#include <stdio.h>

int main(void) {
    printf("정수: %d\n", 42);
    printf("실수: %.2f\n", 3.14);
    printf("합계: %d + %d = %d\n", 3, 5, 3 + 5);
    return 0;
}
```

예상 출력:
```
정수: 42
실수: 3.14
합계: 3 + 5 = 8
```

`%d`는 정수(integer)를 출력하는 자리표시자(format specifier),
`%.2f`는 소수점 아래 2자리까지 출력하는 자리표시자다.
