## 문제 1: 배열 합계와 평균 (난이도: ★☆☆)

정수 배열 {85, 90, 78, 92, 88, 76, 95, 80}의 합계와 평균을 출력하시오.

출력 형식:
```
합계: 684
평균: 85.5
```

## 문제 2: 역순 문자열 출력 (난이도: ★☆☆)

문자열을 받아 역순으로 출력하는 함수를 작성하시오:

```c
void print_reverse(const char s[]);
```

테스트:
```
print_reverse("Hello") -> "olleH"
print_reverse("abc")   -> "cba"
```

---

## 문제 3: 문자열 길이 함수 구현 (난이도: ★★☆)

표준 라이브러리의 strlen과 동일하게 동작하는 my_strlen을 작성하시오.
빈 문자열("")에 대해서도 올바르게 동작해야 한다.

```c
int my_strlen(const char s[]);
```

테스트:
```
my_strlen("Hello")  -> 5
my_strlen("")       -> 0
my_strlen("A")      -> 1
```

---

## 문제 4: 공백 제거 (난이도: ★★☆)

문자열 앞뒤의 공백을 제거하는 함수를 작성하시오 (원본 배열을 직접 수정):

```c
void trim(char s[]);
```

테스트:
```
"  Hello  " -> "Hello"
"  Hi"      -> "Hi"
"World  "   -> "World"
"NoSpace"   -> "NoSpace"
```

힌트: 뒤쪽 공백을 먼저 제거(\0으로 덮어쓰기)한 뒤, 앞쪽 공백은 문자들을 앞으로 이동.

---

## 문제 5: 문자 빈도 세기 (난이도: ★★★)

문자열에서 각 알파벳의 등장 횟수를 세는 프로그램을 작성하시오.
대소문자를 구분하지 않으며, 등장한 문자만 출력한다.

입력 문자열: "Hello World"
출력:
```
d: 1
e: 1
h: 1
l: 3
o: 2
r: 1
w: 1
```

힌트: 크기 26인 int 배열을 사용. 'a'를 빼서 인덱스로 변환.
