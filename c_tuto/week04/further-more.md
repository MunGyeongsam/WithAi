## 1. 버퍼 오버런 (Buffer Overrun) 사례

1988년 모리스 웜(Morris Worm)은 Unix의 gets() 함수가 입력 길이를 검사하지 않는 점을 이용했다:

```c
/* 위험한 코드 */
char buf[16];
gets(buf);  /* 사용자가 100글자를 입력하면? → 메모리 파괴! */
```

이 때문에 gets()는 C11 표준에서 완전히 삭제되었다.
대안: `fgets(buf, sizeof(buf), stdin)` — 최대 크기를 명시한다.

## 2. 문자열과 메모리 레이아웃

```c
char s[] = "Hello";    /* 스택에 6바이트 복사. 수정 가능 */
char *p = "Hello";     /* 읽기전용 영역을 가리킴. 수정 불가! */
```

```c
p[0] = 'h';  /* undefined behavior! 프로그램 죽을 수 있음 */
s[0] = 'h';  /* 안전. s는 자신만의 복사본을 가짐 */
```

이 차이는 5주차(포인터)에서 자세히 다룬다.

## 3. 유용한 문자 검사 함수들 (ctype.h)

```c
#include <ctype.h>

isalpha(c)  /* 알파벳인가? */
isdigit(c)  /* 숫자인가? */
isspace(c)  /* 공백/탭/줄바꿈인가? */
toupper(c)  /* 대문자로 변환 */
tolower(c)  /* 소문자로 변환 */
```

직접 'A' <= c && c <= 'Z'로 비교하는 것보다 이식성이 좋다.
