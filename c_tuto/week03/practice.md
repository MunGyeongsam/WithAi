## 문제 5: 간이 계산기 (난이도: ★★★)

switch를 사용해서 간단한 사칙연산 계산기를 작성하시오:

- 두 정수 a, b와 연산자 op(char)가 주어진다.
- op가 +, -, *, / 중 하나일 때 계산 결과를 출력한다.
- /에서 b == 0이면 "0으로 나눌 수 없습니다"를 출력한다.
- 알 수 없는 연산자면 "지원하지 않는 연산자입니다"를 출력한다.

```c
void calculate(int a, int b, char op);
```

테스트:
```
calculate(10, 3, '+')  -> "10 + 3 = 13"
calculate(10, 0, '/')  -> "0으로 나눌 수 없습니다"
calculate(10, 3, '&')  -> "지원하지 않는 연산자입니다"
```
