# Week 11 연습문제

---

## 문제 1: 파일 쓰기 (난이도: ★☆☆)

1~100까지의 숫자를 한 줄에 하나씩 파일 "numbers.txt"에 쓰는 프로그램을 작성하시오.

---

## 문제 2: 파일 줄 수 세기 (난이도: ★☆☆)

파일 이름을 명령줄 인자로 받아, 해당 파일의 줄 수를 출력하시오.
파일이 없으면 오류 메시지를 출력할 것.

---

## 문제 3: 파일 복사 프로그램 (난이도: ★★☆)

source 파일을 dest 파일로 복사하는 프로그램을 작성하시오.
바이너리 안전하게(fread/fwrite) 구현할 것. 오류 처리 포함.

사용법: `./copy source.txt dest.txt`

---

## 문제 4: CSV 파싱 (난이도: ★★★)

다음 형식의 CSV 파일을 읽어 구조체 배열에 저장하시오:

```
Kim,22,3.8
Lee,21,4.0
Park,23,3.5
```

구조체: { char name[20]; int age; double gpa; }
GPA 기준 내림차순으로 정렬 후 출력.

---

## 문제 5: 간이 로그 시스템 (난이도: ★★★)

로그 레벨(INFO, WARN, ERROR)과 메시지를 파일에 기록하는 함수를 작성하시오:

```c
void log_write(const char *level, const char *msg);
```

출력 형식: `[INFO] 2026-01-15 14:30:00 - 서버 시작`
(시간은 time() 함수 사용)
