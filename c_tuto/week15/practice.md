# Week 15 연습문제

## 프로젝트 실습

이번 주는 별도 문제 대신 **미니 프로젝트를 직접 구현**합니다.

### 필수 과제

1. 강의 노트의 주소록 프로그램을 4개 파일로 분리해 구현하시오.
2. 최소 5개의 테스트 케이스를 작성하시오:
   - 빈 주소록에서 검색
   - 추가 후 검색
   - 삭제 후 목록 확인
   - 저장 후 새로 로드해서 데이터 유지 확인
   - 용량 초과 시 자동 확장

### 선택 과제 (추가 도전)

3. 이름 부분 일치 검색 구현 (strstr 활용)
4. 이름 기준 정렬 기능 추가 (qsort 활용)
5. Makefile 작성
