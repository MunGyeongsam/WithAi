# Week 05 강의: 포인터 기초

---

## 왜 포인터(pointer)가 필요한가

지금까지 변수는 "값"만 다뤘다. 하지만 현실에서는:
- 함수에서 호출자의 변수를 수정하고 싶을 때
- 큰 데이터를 복사하지 않고 전달하고 싶을 때
- 동적으로 메모리를 할당하고 싶을 때

이 모든 것에 **포인터(주소를 저장하는 변수)**가 필요하다.

비유: 책 자체를 복사하는 대신, "도서관 3층 A-15번 선반"이라는 **위치 정보**를 적어두는 것.

---

## 메모리 주소의 개념

컴퓨터 메모리의 모든 바이트에는 고유한 **주소(address)**가 있다:

```
주소:  100  101  102  103  104  105  106  107
     ┌────┬────┬────┬────┬────┬────┬────┬────┐
     │    │    │ 42 │ 42 │ 42 │ 42 │    │    │
     └────┴────┴────┴────┴────┴────┴────┴────┘
               └──── int x = 42 ───┘
                 x의 주소: 102
```

`int x = 42;`를 선언하면, 컴파일러가 메모리 어딘가에 4바이트를 확보하고 42를 저장한다.

## 포인터 선언과 사용

### & (주소 연산자): 변수의 주소를 구한다
### * (역참조 연산자): 주소가 가리키는 값을 읽거나 쓴다

```c
#include <stdio.h>

int main(void) {
    int x = 42;
    int *p = &x;   /* p는 x의 주소를 저장한다 */

    printf("x의 값: %d\n", x);      /* 42 */
    printf("x의 주소: %p\n", (void*)&x);  /* 예: 0x7fff1234 */
    printf("p의 값(=x의 주소): %p\n", (void*)p);
    printf("p가 가리키는 값: %d\n", *p);   /* 42 */

    /* 포인터를 통해 x를 수정 */
    *p = 100;
    printf("수정 후 x: %d\n", x);   /* 100 */
    return 0;
}
```

### 핵심 정리

| 표현 | 의미 |
|------|------|
| `int *p` | "p는 int를 가리키는 포인터" 선언 |
| `&x` | x의 주소 |
| `*p` | p가 가리키는 값 (역참조) |
| `p = &x` | p에 x의 주소를 저장 |
| `*p = 100` | p가 가리키는 곳에 100을 저장 |

---

## 포인터 선언 읽는 법

**규칙: 변수 이름에서 시작해서, * 하나당 "~를 가리키는 포인터"로 읽는다.**

```c
int *p;         /* p는 int를 가리키는 포인터 */
double *dp;     /* dp는 double을 가리키는 포인터 */
char *cp;       /* cp는 char를 가리키는 포인터 (문자열에 자주 사용) */
```

> ⚠️ 주의: `int *p, q;`에서 q는 포인터가 아니라 일반 int이다!
> `*`는 변수 이름에 붙는다. 타입에 붙는 것이 아니다.
> 명확하게: `int *p; int *q;` 또는 `int *p, *q;`

## 포인터를 함수에 전달하기

### 값에 의한 호출 (call by value) - 기본

```c
void try_to_change(int n) {
    n = 999;  /* 복사본만 바뀜. 원본은 그대로 */
}

int main(void) {
    int x = 42;
    try_to_change(x);
    printf("x = %d\n", x);  /* 여전히 42 */
    return 0;
}
```

### 포인터로 원본 수정 (simulate call by reference)

```c
void real_change(int *ptr) {
    *ptr = 999;  /* 원본을 직접 수정! */
}

int main(void) {
    int x = 42;
    real_change(&x);
    printf("x = %d\n", x);  /* 999 */
    return 0;
}
```

비유: 값 전달은 "책을 복사해서 주기", 포인터 전달은 "책꽂이 위치를 알려주기".

## swap 함수: 포인터의 대표 예제

두 변수의 값을 교환하는 함수:

```c
#include <stdio.h>

void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

int main(void) {
    int x = 10, y = 20;
    printf("교환 전: x=%d, y=%d\n", x, y);
    swap(&x, &y);
    printf("교환 후: x=%d, y=%d\n", x, y);
    return 0;
}
```

실행 결과:
```
교환 전: x=10, y=20
교환 후: x=20, y=10
```

> 포인터 없이 swap을 구현하는 것은 **불가능**하다.
> C는 항상 값 복사로 인자를 전달하므로, 원본을 바꾸려면 주소를 넘겨야 한다.

## NULL 포인터

아무것도 가리키지 않는 포인터:

```c
int *p = NULL;  /* 아직 유효한 주소를 가리키지 않음 */

if (p != NULL) {
    printf("%d\n", *p);  /* 안전하게 사용 */
} else {
    printf("포인터가 비어있음\n");
}
```

> ⚠️ NULL 포인터를 역참조하면 프로그램이 즉시 죽는다 (segmentation fault).
> 항상 NULL 검사 후 사용하는 습관을 들인다.

## 포인터와 배열의 관계

배열 이름은 첫 번째 원소의 주소와 같다:

```c
int arr[5] = {10, 20, 30, 40, 50};
int *p = arr;  /* &arr[0]과 동일 */

printf("%d\n", *p);       /* 10 (arr[0]) */
printf("%d\n", *(p+1));   /* 20 (arr[1]) */
printf("%d\n", *(p+2));   /* 30 (arr[2]) */
```

### 포인터 산술(pointer arithmetic)

| 표현 | 의미 |
|------|------|
| `p + 1` | 다음 원소의 주소 (int면 4바이트 뒤) |
| `p + i` | i번째 뒤 원소의 주소 |
| `*(p + i)` | `p[i]`와 동일 |
| `p++` | p를 다음 원소로 이동 |

```c
/* 포인터로 배열 순회 */
for (int *ptr = arr; ptr < arr + 5; ptr++) {
    printf("%d ", *ptr);
}
/* 출력: 10 20 30 40 50 */
```

## 배열 vs 포인터: 차이점

```c
int arr[5] = {1,2,3,4,5};
int *p = arr;

sizeof(arr)  /* 20 (5 * 4바이트) — 배열 전체 크기 */
sizeof(p)    /* 8 (64비트 시스템에서 포인터 크기) */

arr = p;     /* 오류! 배열 이름은 재대입 불가 */
p = arr;     /* OK. 포인터는 다른 주소를 가리킬 수 있다 */
```

> 배열은 "고정된 주소", 포인터는 "바꿀 수 있는 주소 저장 변수".

## 자주 틀리는 포인트 3가지

1. **초기화 안 된 포인터 사용**
   ```c
   int *p;      /* 쓰레기 주소! */
   *p = 42;     /* undefined behavior → 보통 프로그램 죽음 */
   ```

2. **&를 빠뜨리고 함수에 전달**
   ```c
   void set(int *ptr) { *ptr = 99; }
   int x = 0;
   set(x);     /* 경고! x의 값(0)을 주소로 해석 → 위험 */
   set(&x);    /* 올바름 */
   ```

3. **포인터 타입 불일치**
   ```c
   double d = 3.14;
   int *p = &d;   /* 경고! double*를 int*에 대입 → 값이 깨짐 */
   ```

## 이번 주 핵심 요약

| 개념 | 한 줄 요약 |
|------|-----------|
| 포인터 | 메모리 주소를 저장하는 변수 |
| & | 변수의 주소를 구하는 연산자 |
| * | 주소가 가리키는 값을 읽고 쓰는 연산자 |
| NULL | 아무것도 가리키지 않음을 나타내는 값 |
| 포인터 전달 | 함수에서 호출자의 변수를 수정할 수 있음 |
| 배열과 포인터 | 배열 이름 ≈ 첫 원소 주소, 포인터 산술로 순회 |
