## 1. const와 포인터의 조합

```c
const int *p;      /* p가 가리키는 값을 수정 못함 (읽기 전용) */
int *const p;      /* p 자체를 수정 못함 (다른 곳을 가리킬 수 없음) */
const int *const p; /* 둘 다 수정 못함 */
```

읽는 법: const가 *의 왼쪽이면 "가리키는 값" 보호, 오른쪽이면 "포인터 자체" 보호.

---

## 2. void 포인터

```c
void *vp;  /* 아무 타입이든 가리킬 수 있는 범용 포인터 */

int x = 42;
vp = &x;  /* OK */

/* 사용하려면 캐스트 필요 */
int *ip = (int*)vp;
printf("%d\n", *ip);
```

malloc이 void*를 반환하는 이유: 어떤 타입으로든 쓸 수 있게 하기 위해.

---

## 3. 포인터의 크기

포인터 자체의 크기는 가리키는 타입과 무관하다:
- 32비트 시스템: 모든 포인터 4바이트
- 64비트 시스템: 모든 포인터 8바이트

```c
printf("%zu\n", sizeof(int*));     /* 8 */
printf("%zu\n", sizeof(double*));  /* 8 */
printf("%zu\n", sizeof(char*));    /* 8 */
```
