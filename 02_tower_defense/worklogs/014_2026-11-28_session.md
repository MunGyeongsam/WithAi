## 회고

1. 입력 전달 계약은 source seam 없이 실제 모듈 조합만으로 관찰할 수 있었다.
2. snapshot 테이블 재사용 때문에 1회 소비 검사는 mutable reference가 아니라
   라우팅 시점에 기록한 scalar 값으로 비교했다.
3. HUD panel과 유효 map row가 겹치는 좌표를 사용하고, `handleTap`이 false를
   반환하는 fixture에서 wall이 실제 배치되는 것을 확인해 소비 회귀를 잡는
   테스트임을 검증했다.
4. 실패 상태 fingerprint에 grid, path, 경제 총계, wave queue/spawning/timer를
   포함해 gold·lives만 같은 부분 변경을 놓치지 않는다.
