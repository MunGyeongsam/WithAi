## 회고

1. 기존 public alpha 의미를 유지한 채 render alpha 관찰 API 한 개만 추가했다.
2. 코어 fixture는 script 위치 기준 `package.path`를 사용해 저장소 루트에서
   실행할 수 있다.
3. 검토 뒤 프레임 간 accumulator 전달과 SceneStack pop 복귀의 두 계약을
   보강했고, 첫 accumulator fixture의 부동소수점 경계값은 구현 변경 없이
   안정적인 입력으로 조정했다.

## 미해결 문제와 위험

- InputAdapter의 `snapshot`은 매 update마다 같은 테이블을 재사용하므로
  소비자는 다음 update 전 값 보존을 가정하면 안 된다. 후속 routing 테스트는
  snapshot 전달 시점을 함께 보호해야 한다.
- `FixedTimestep`의 `getAlpha()` raw 값은 1을 초과할 수 있다. 렌더 사용 시
  `getRenderAlpha()`를 선택하는 계약은 향후 `main.lua` 호출부 검토가 필요하다.
- 전체 LÖVE 실행은 이번 변경에서 수행하지 않았으므로 실제 렌더 보간 사용은
  후속 입력/렌더 작업에서 별도 확인한다.
