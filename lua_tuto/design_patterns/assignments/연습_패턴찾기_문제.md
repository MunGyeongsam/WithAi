# 연습: 정의·상황으로 패턴 찾기 (Pattern Identification Drill)

> 대상: `lua_tuto/design_patterns`의 22개 패턴
> 방식: 각 문항의 **간단한 정의 또는 상용 예시**를 읽고, 가장 알맞은 패턴 하나를 적는다.
> 각 패턴마다 **4문항**씩, 총 **88문항**을 뒤섞어 배치했다.
> 정답과 결정적 신호는 [연습_패턴찾기_정답.md](연습_패턴찾기_정답.md)에 있다.

**패턴 목록 (보기)**
- 생성(5): `abstract_factory` `builder` `factory_method` `prototype` `singleton`
- 구조(7): `adapter` `bridge` `composite` `decorator` `facade` `flyweight` `proxy`
- 행동(10): `chain_of_responsibility` `command` `iterator` `mediator` `memento` `observer` `state` `strategy` `template_method` `visitor`

> 팁: 정답을 외우지 말고 **결정적 신호(trigger keyword)** 를 찾는 연습을 한다. (예: "전이" → state, "통째로 교체" → strategy)

## 활용법

- 1차: 보기 없이 패턴 이름을 직접 적어 본다.
- 2차: 틀린 문항만 모아 **결정적 신호 키워드**를 밑줄 긋고 다시 푼다.
- 심화: 각 문항에서 "왜 비슷한 다른 패턴이 아닌지"를 한 줄로 쓴다. (예: 1번 → state가 아닌 이유: 상태 전이가 없다)
