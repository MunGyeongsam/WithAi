## 2. 규칙 · 스킬 · 워크플로 · 에이전트 — 소개 요점

본문: [작성_가이드.md](작성_가이드.md). 소개 순서는 **규칙 → 스킬 → 워크플로 → 에이전트** (적용 범위가 넓은 것에서 좁은 것으로, 자동에서 수동으로).

| 도구 | 한 줄 개념 | 강조할 작성 요점 | 사용 예시 (가이드 절) | 꼭 보여 줄 예시 |
|---|---|---|---|---|
| 규칙 | 항상 지키는 교칙 | **짧고 절대적인 것만.** 길면 한도에 걸린다 | 1-3: ① `AGENTS.md` 공통 ② Model 폴더 glob ③ 제출 직전 manual | ② — "필요할 때만 켜지는 규칙" |
| 스킬 | 이럴 때 이렇게 (매뉴얼) | **`description` = 무엇 + 언제.** Gemini 앱과 공용 | 2-3: ① `lua51-guard` 검토 ② 스킬 겹쳐 쓰기 ③ 자작 `wave-format` | ③ — "같은 설명을 두 번 했다 → 스킬" |
| 워크플로 | 이 순서대로 (체크리스트) | **단계마다 확인 가능한 행동 + 멈추는 지점** | 3-3: ① `/start-session` ② `/end-session` ③ 자작 `/add-enemy-type` | ③ — 테스트 → Model → View → 경계 검사 순서 강제 |
| 에이전트 | 이 역할만 (권한 제한 동료) | **`tools` 최소화.** 읽기 전용이면 실수로도 못 고친다 | 4-3: ① `planner` ② `lua-reviewer` ③ 자작 `report-helper` | ③ — 보고서 표 초안, "왜 썼는지"는 학생이 |

**Gemini 앱만 쓰는 학생**에게는 2행(스킬)만 확실히 익히게 한다. 규칙은 스킬로 대신하고, 워크플로와 에이전트는 개념만 알면 된다.

**과제 연결:** 작성 가이드 5절 "내 스킬(또는 워크플로·에이전트) 1개 만들기". 적용 전후 비교를 로그에 남기면 AI 협업 로그의 "개선 이력"으로 인정한다.

## 3. 프롬프트 예시 10쌍 — 활용 방법

본문: [프롬프트_예시집.md](프롬프트_예시집.md). 과제 작업 순서(설계 → 패턴 → 구현 → 테스트 → Lua 문법 → 디버깅 → 리팩터링 → 에이전트 → 마무리)로 배열했다.

| # | 상황 | 과목 | 수업에서 쓰는 법 |
|---|---|---|---|
| 1 | 설계 | 게임인공지능 | **라이브 시연 1순위.** Gemini 앱 새 대화 2개에서 나쁜 예 / 좋은 예를 나란히 실행 |
| 2 | 패턴 선택 | 게임인공지능 | "증상으로 설명하면 AI 가 패턴을 정확히 고른다" |
| 3 | 구현 | 공통 | "한 번에 상태 1개" — 나쁜 예의 결과 길이를 보여 준다 |
| 4 | 테스트 먼저 | 공통 | 경계값(정확히 150)이 `<` / `<=` 실수를 잡는 이유 |
| 5 | 웨이브 파서 | 게임시스템설계 | **라이브 시연 2순위.** `gmatch` 가 잘못된 토큰을 조용히 건너뛰는 함정 (아래 확인 메모) |
| 6 | 메타테이블 상속 | 게임시스템설계 | "`__index` 탐색 순서를 설명하라" → 구술 대비 |
| 7 | 디버깅 | 공통 | 스택 트레이스가 없으면 왜 못 찾는지 |
| 8 | MVC 리팩터링 | 게임인공지능 | 도구 출력(layer_check)을 그대로 붙이는 습관 |
| 9 | 에이전트 범위 제한 | 공통 | Antigravity 시연과 함께. 범위 밖 변경 = 로그의 거절 사례 |
| 10 | 인계 메모와 로그 | 공통 | 로그 채점과 직결. 1일차 첫 세션 끝에 소개 |

**실습 제안:** 학생에게 나쁜 예만 보여 주고 6요소로 고쳐 쓰게 한 뒤 좋은 예와 비교한다. 고쳐 쓴 Before / After 가 **로그 #0** 이 된다.

**확인 메모 (예시집 사실 검증, LuaJIT 2.1)**
- 5번: `("A3 B C1 x"):gmatch("(%a)(%d+)")` 결과는 `A3 C1` — `B`, `x` 를 에러 없이 건너뛴다.
- 8번: `layer_check` 의 실패 출력 형식 `FAIL  models/EnemyModel.lua:<줄>  [love]  <코드>` 를 week04 코드로 재현해 확인했다.
- 6번: week04 `class.lua` 는 `class(base)` 로 상속, `Class(...)` 로 생성하며 `init` 을 호출한다. `EnemyModel` 도 `class()` 로 만들어져 있다.
