## 2. 시간이 밀릴 때 줄이는 순서
1. 구현 6단계(연출)를 **flash 하나만** 남기고 생략 — 고통 ❶(Model-View 결합)은 flash 만으로도 보인다.
2. 기능 추가 과제를 **A(유도)로 고정** — B 보다 작다.
3. 그래도 부족하면 학생 코드 대신 [galaga_monolith/main.lua](examples/galaga_monolith/main.lua)를 받아 **기능 추가부터** 시작.
- **줄이면 안 되는 것:** 기능 추가 + 전파 세기. 이게 이번 주의 존재 이유다.

## 3. 시연 순서 (회고 시간, 15분)
1. `diff galaga_monolith/main.lua galaga_monolith_full/main.lua | grep -E '^[0-9]'` → 변경 블록 41개가 파일 앞·중간·뒤에 퍼진 것을 보여준다. (`| wc -l` 을 붙이면 개수만 나온다)
2. `[B5]` 지점: "보스 원형 탄막 때문에 **일반 적 총알** 생성 코드까지 바뀌었다" — 가장 강한 사례.
3. basics 06 README 5절 표를 띄우고 "같은 종류의 추가가 저기선 파일 1~2개"로 대비.
4. 질문으로 마무리: "보스를 던전처럼 추가하려면 무엇을 나눠 두었어야 했을까?" → 3주차 예고.

| 질문 | 답의 방향 |

## 5. 자주 막히는 곳
- **역순 순회 + `table.remove`**: 앞에서부터 지우면 원소를 건너뛴다. `for i = #t, 1, -1`.
- **충돌 루프에서 총알 제거 후 `break` 누락**: 이미 지운 총알로 다음 적과 또 판정한다.
- **편대 하강 무한 반복**: 경계 판정을 이동 *후*에 하면 끝에 끼어 매 프레임 내려온다. 이동 *전* 예측(`maxx + dx`)으로 판정.

## 6. 측정 프로토콜(1-4) 운영 주의
- T1/T2 측정 뒤 **반드시 되돌리게** 한다(측정용 변경이 게임에 남으면 T2 기준이 오염됨).
- AI 도구가 학생마다 다르므로 **학생 간 숫자 비교 금지**. 개인 추세(T1→T2→T3)만 본다.
- AI 를 쓰지 않는 학생은 "내가 직접 P 를 구현할 때 고친 곳"을 같은 표에 적는다.
